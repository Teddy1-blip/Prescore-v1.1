# Prescore Studio v0.1 · протокол приёмки

Проверен локальный синтетический preview на Node.js 24.22.1 и в Chromium. Продуктовая база и атлас указывают на `cef0145f890a91fe8be58d5c740e7c7d250f4af8`. Проверены состав обоих Excel-файлов, JSON атласа, Readme, QA, Blueprint, реальные реестры и fixture Integration B. В книге атласа 25 листов, включая 22_Связи и 24_Паспорта_правил. В исходном конструкторе пять листов.

## Результаты команд

Из корня репозитория под Bash:

```sh
node --experimental-strip-types --test tests/{bank-statement-metrics-v2,canonical-production-v1,financial-analysis-v2,integration-b-chain,prescore-index-v1,risk-engine-v1,risk-overlap-suppression,revenue-overlap-policy,rnp-general-index-policy,recommendations-v1,action-plan-v1,context-engine-v1}.test.mjs
node --experimental-strip-types --test tests/prescore-studio.test.mjs
```

| Проверка | Результат |
|---|---|
| До изменений, 12 существующих наборов | 1 816 зарегистрированных тестов, 1 814 успешно, два сбоя |
| После изменений, тот же список | 1 816, 1 814 успешно, те же два сбоя |

| Совпадение полных дефолтных результатов | Три SHA-256 сериализованных canonical outputs совпали с полученными **до** правок. Дополнительно deepEqual обычного вызова и Studio без эксперимента |
| HTTP от входа до импорта | Без сессии реестр закрыт. После локального подтверждения выполнены calculate → save → read version/run → export → import. Из импортированного пакета восстановился тот же draft |
| Браузер на полном реестре | Пройдены открытие, обзор, масштаб, pan, группа, поиск, выбор, входы, формула, условие рекомендации, полный пересчёт, diff, сохранение, reload, повторное открытие, baseline и загрузка JSON через экспорт |
| Две компании | В режиме подготовки проверены обе. На «Интеграции Б» Index изменился с 1000 до 849. У «Сервис Лаб» оба значения отсутствовали, оба вызова вернули COMPLETE |

Для воспроизведения тестов существующего проекта требуются его зависимости. Браузерный путь проходился через loopback-harness. В изолированной среде полный Next build, интеграция маршрута с рабочими Auth/БД и весь набор `npm test` локально не запускались. Предыдущий [GitHub QA базового SHA](https://github.com/Teddy1-blip/Prescore-v1.1/actions/runs/42793328381) имеет conclusion failure на job candidate, четыре последующих job пропущены. По этому факту нельзя установить причину отказа инфраструктуры.

### Исходные расхождения

- `tests/recommendations-v1.test.mjs` прерывается при загрузке fixture с `RECOMMENDATION_GOLDEN_FINGERPRINT_MISMATCH:REC-RU-023`.
- `tests/action-plan-v1.test.mjs`, тест `baseline fingerprints present and exact`, ожидает `action-plan-golden:db44744bf8eaaf1d36f9cbbba2b69fed`. Фактическое значение до и после — `action-plan-golden:3b4e0d0a26fdc112357e2b5ab4a1a5a6`.

Ожидания и существующие fingerprints сохранены без правок.

## Что проверяет Studio

| Условие | Наблюдение |
|---|---|
| Реальный downstream | Формула без дебиторки дала 0,8333 вместо 2. Сработал риск MEDIUM. Финансовый компонент 400 → 328, сумма 1000 → 928, потолок 849. Кредитное заключение содержит новое число существенных рисков. |
| Независимые результаты | Осторожный и верхний предел обслуживания долга остались 100 000 и 150 000 ₽/мес. Изменение только текста рекомендации сохранило Index. |
| Триггер | При риске ликвидности существующий движок выбрал 19 рекомендаций. У новой рекомендации с условием дефицита оборотного капитала срабатывания не было. После замены условия на выявленный риск ликвидности действий стало 20, Index остался 849. |
| Ограничения | Пустая строка БФО, нулевой знаменатель и отсутствие источника отражаются явно. Отключённое правило и недостаточность данных имеют разные status/reasonCodes. Неверная дата или принадлежность компании отклонены. |
| Безопасная методология | Проверки формулы, единиц, периода, типа, сложности, обязательных входов, произвольного кода и циклов. Несовместимый порт не присоединяется. |
| Параллелизм | Два одновременно работающих Worker дали ожидаемые разные результаты. Следующий обычный вызов воспроизвёл baseline. Отмена и смена ревизии инвалидируют прежний ответ. |
| Доступ и версии | CLIENT, AGENT и запрос без роли получили 403. Проверены origin, раздельные пространства владельцев, параллельное сохранение, повторное открытие, формат, checksum и совместимость. Импорт не может отметить пакет утверждённым. |
| Повторяемость | Оба поставляемых пакета воспроизвели хеши результатов на фиксированной версии. |

## Размер карты и снимки

Базовый граф содержит **1 653 узла, 22 области и 4 100 связей**. Из них 2 036 RELATED, 1 909 EVIDENCE и 155 типизированных расчётных зависимостей.
