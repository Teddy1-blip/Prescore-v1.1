Расхождения обнаружены на ревизии `80f32a17` при сравнении с ранее запущенным staging. Этот документ описывает основания для изменений ожиданий. Контрольные наборы остаются детерминированными.

| --- | --- |

Действия ссылаются на учтённый риск и собственные банковские факты. Изменены только два отпечатка плана. |
| 2. Динамический рендер защищённых страниц | В объявлении режима `force-dynamic` страницы администрирования восстановлено принятое в проекте написание. Тест и режим рендеринга сохранены. |

Повторное усиление штрафа по БФО со 140 до 154 за тот же банковский факт было снято принятой политикой. Итоговый индекс 699, ранее 687. Обновлены два отпечатка входов оценки, требования к драйверам и порядку сохранены. |
| 4. Межблочная проверка Debt Capacity | Проверка блоков 8–12 останавливалась в том же наборе Readiness до расчёта ёмкости. Повторно выполняются исходные межблочные проверки. |
| 5. Financing Readiness | RDY-RU-037 и 040 получают скорректированный индекс 699 из одного набора фактов в двух порядках. Изменены два отпечатка входов, оценка готовности LOW и требование идентичного выхода сохранены. |
| 6. Recommendations | В REC-RU-023 совпадают периоды БФО и банковских поступлений. Пересечение снимает второй штраф. Сверка поступлений с выручкой сохраняет первичный банковский источник. Обновлён один отпечаток входа. Первоначальное ожидание рекомендации сохранено. |

| 10. Сообщение агрегатора о РНП | Сообщения агрегатора недостаточно для вывода о действующей записи. Проверены отсутствие сигнала и действия, а также отдельное состояние общего стопа. |
| 11. Смена статуса источника РНП | При сбое источника меняется отпечаток решения, значение факта становится неизвестным, подтверждённый сигнал исчезает. Отдельно проверена запись без даты планового окончания. |

## Основания действий

Для пересекающихся поступлений и выручки и для прокси чистых активов и капитала используется фактически сработавшее правило с явной ссылкой на сохранившийся риск. Его идентификатор сверяется с исходными фактами, компанией и датой оценки. Сумма, источник и причина действия берутся из подтверждающего наблюдения. Приоритет относится к единому экономическому риску. Это также работает с сохранёнными оценками старого формата. Неполные, неоднозначные и чужие основания исключаются. Правила о закрытых обязательствах, исторической просрочке, повторном убытке и ограничении действий при общем стопе продолжают действовать.

Регрессии проверяют наличие четырёх действий в плане, их горизонт, отсутствие дублей, один вклад в индекс, а также отсутствие действий при росте поступлений, недостаточном покрытии или потере ссылки на источник. Для отрицательного прокси отдельно проверяется запрос подтверждённого расчёта чистых активов.

На следующем шаге сборки ESLint также потребовал ключи React для шести ячеек таблиц, компонент Next Link для внутренней ссылки Studio и однозначное имя функции входа в браузерном тесте. Ключи не добавляют атрибутов в DOM. Условия переходов, классы оформления и контент кабинета сохранены.
