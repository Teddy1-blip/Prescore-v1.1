## Интеграция аналитики — проверка кода

POST /api/analysis вызывает analyzeBankStatements, сохраняет результат и применяет entitlement. В analyzeBankStatements подключены source manifest/integrity, Bank Statement Metrics v2, reconciliation, portfolio и risk shadow. Financial Analysis подключён в отдельных обработчиках Checko / квартальной отчётности; внешние запросы не выполнялись.

Страница /dashboard/report-v2 читает tests/fixtures/client-report/preview-models.json и защищена dashboard layout. Она не читает сохранённый анализ клиента. В app не найден вызов buildClientReportModel/buildClientReportShadow. Поэтому Block 18 — preview, интеграция нового отчёта в сквозной сценарий НЕ подтверждена. Наличие движков Index/Readiness/Capacity/Product/Recommendations/Explainability в lib само по себе не доказывает их включение в пользовательский сценарий.

## Что требуется для продолжения

Работающий подтверждённый тестовый аккаунт через безопасный вход; для проверки остальных ролей — соответствующие тестовые аккаунты. SMTP нужно настроить через защищённый интерфейс на реального выбранного провайдера. Отправка писем остаётся отдельно не разрешённой. Для размеров экрана и печати нужен поддерживаемый браузерный механизм, которого текущий API не предоставляет.

GitHub commits/main, production, DNS/prescore.ru, пароли БД, тарифы, новые ресурсы, реальные клиентские данные, платежи и платные внешние вызовы не изменялись/не использовались.
