# RC1 security boundary

The standalone proxy enforces same-origin + Sec-Fetch-Site for every user mutation. The acquiring notification route is the sole CSRF exemption and verifies cryptographic signature/mapping before effects. Earlier proxy incorrectly required browser Origin on provider callbacks; fixed for actual server E2E. Streamed body limits apply even without Content-Length. Source uploads add ZIP central-directory limits before XLSX decompression. Names/search/page/body/chat/AI/callback bounds remain explicit.

PostgreSQL atomic rate limits use keyed hashes, fixed windows, indexed expiry and cleanup<=100 rows per request. Verified user ID is the authenticated identity; anonymous operations use a shared global bucket rather than trusting spoofable forwarding headers or arbitrary cookies. BetterAuth adds persistent per-credential login/reset/verification limits. Invalid callbacks are separately limited after signature rejection; valid provider retries are never counted against that bucket. Limiter infrastructure failure returns503, no memory-only fallback. Operational metrics count only persisted events; DB failures may be visible only in sanitized logs.

CSP uses fresh per-request script nonce/strict-dynamic and dynamic Next rendering, no script unsafe-inline/eval or wildcard. Style unsafe-inline is needed for current product inline styles/native meters, narrowly documented; font/image/connect default self. frame-ancestors none, nosniff, Referrer/Permissions policies. HSTS only for explicit HTTPS production mode. HTTPS session cookies Secure+HttpOnly+SameSite=Lax; isolated RC loopback HTTP is explicit and cannot authorize production Fake. No raw secret headers/body/provider payload in logs; request IDs sanitized and internal errors return safe diagnostics.

Verified fixes include removed automatic ADMIN escalation; server-derived chat author role/name; attached documents must belong to the logical application; database/provider/filesystem errors sanitized; leading-whitespace CSV formula injection escaping; stable bounded Broker/partner pagination. Existing owner/assigned-broker/curator boundaries remain required.

Dependencies resolved versions are exact, lockfile retained; npm audit production critical/high is a CI gate with sanitized report. No blind major upgrades. Native PDF extraction uses the existing canonical source contract; credit formulas/risk rules remain untouched. Reference for nonce/dynamic rendering: https://nextjs.org/docs/app/guides/content-security-policy .
